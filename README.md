# Ivy Skills
> 将重复操作封装为可复用的 Skills，讨 TAI 帮你解放双手。

## 这是什么

Ivy Skills 是一套面向 Claude Code 的技能集合，专注于**流程自动化**和**重复工作降本增效**。

日常开发中有大量繁琐、重复、但又不得不做的操作——浏览器登录、网页抓取、文件批量处理、表单填写、环境检查……这些事情做一次不难，做一百次就是折磨。

**把它们封装成 Skill，一次编写，无限复用。**

## 核心理念

- **自动化优先**：能自动化的绝不手动，能一键完成的绝不三步
- **Skill 即复用**：将重复操作标准化、参数化、可组合
- **降本增效**：减少人工介入，降低出错率，释放创造力
- **开源开放**：自由使用、自由修改、自由分发

## 已有 Skills

| Skill | 用途 |
|-------|------|
| `web-scan` | 浏览器自动化：网页抓取、表单填写、数据提取（基于 Chromium，保留登录态） |
| 更多 Skills | 持续添加中... |

## 使用方式

Skills 通过 Claude Code 的 `/skill-name` 命令调用，也可以在对话中直接描述需求，Claude 会自动匹配合适的 Skill。
